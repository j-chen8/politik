# Umfrage-Salienz: Quellen & Tier-Herleitung

**Zweck.** Belegbare „Was-bewegt-die-Bürger:innen"-Ebene für die Themen-Frontdoor.
Statt einer fragilen Einzel-Prozentzahl pro Thema (volatil + methodenabhängig +
heimlich redaktionell) leiten wir eine **triangulierte Salienz-Stufe** aus mehreren
Umfragen ab. Angezeigt wird der Quer-Umfrage-Konsens, **alle Quellen zitiert**.

> **Kernbefund Methodik (gehört sichtbar auf die Seite):** Es gibt keine „die"
> Rangfolge. **Offene** Fragen („Was ist das wichtigste Problem?", spontan) heben
> Wirtschaft & Migration; **vorgegebene** Listen („Wählen Sie 3 aus") heben Armut/
> Ungleichheit & Inflation. Einzelwerte sind zudem volatil (Inflation Politbarometer
> April 25 % → Mai 11 %; Migration Eurobarometer 2024 35 % → 2025 19 %). Robust ist
> nur, was über Methoden & Wellen konsistent oben steht.

## Zeit-Basis: Durchschnitt über die Wahlperiode (nicht Momentaufnahme)

Die Initiativen sind ein **kumulierter Bestand** über die ganze Wahlperiode; eine
einzelne Umfrage-Welle dagegen eine Momentaufnahme, die stark schwankt. Fairer
Vergleich = Sorge **über dieselbe Periode gemittelt**. Politbarometer-Periodenmittel
(offene Frage, 21 Wellen, Apr 2025–Mai 2026):

| Ø % | Kategorie | | Ø % | Kategorie |
|---|---|---|---|---|
| 23,9 | Wirtschaftslage | | 8,1 | AfD/Rechte |
| 21,0 | **Zuwanderung** | | 7,6 | Soziales Gefälle |
| 12,2 | Klima / Energie | | 7,6 | Politikverdruss |
| 10,8 | Renten | | 7,1 | Ukraine/Krieg |
| 10,5 | Bundeswehr/Verteidigung | | 5,8 | Gesundheit/Pflege |
| 9,2 | Kosten/Löhne/Preise | | 4,5 | Arbeitslosigkeit |

**Lehre:** Momentaufnahme ≠ Periodenbild. **Zuwanderung** ist im Mai-Snapshot 12 %,
über die Periode aber **21 % (#2)** — sie war lange dominant und fällt erst zuletzt.
Tier-Ordnung wurde entsprechend zeit-korrigiert (Migration hoch, „zuletzt rückläufig").
Politbarometer-Kategorien decken **nicht** alle Themen ab (kein Innere Sicherheit/
Steuern/Bildung/Wohnen) — daher bleibt die Tier-Abstraktion (mehrquellig) nötig; das
Periodenmittel dient zur Zeit-Korrektur, wo die Zeitreihe vorliegt.

## Tier-Definitionen

- **sehr hoch** — durchgängig Top-3 über offene *und* vorgegebene Umfragen.
- **hoch** — Top-5 in mehreren Quellen oder klare Spitze in einer Methode.
- **mittel** — regelmäßig genannt, mittleres Feld.
- **niedrig** — in Umfragen selten top (kann trotzdem hohes Parlaments-Volumen haben).

Zusatz-Flags: `rückläufig` (Welle-zu-Welle stark gefallen), `Divergenz` (Umfrage-
Salienz ≫ Parlaments-Volumen oder umgekehrt — eigene, deskriptiv gerahmte Analyse,
siehe Frontdoor Schicht 2).

## Pflege

Tiers sind robust (ändern sich nicht monatlich). Halbjährlich gegen die neueste PB-/
EB-/IP-Welle prüfen; bei Welle-Sprung das `rückläufig`/`Divergenz`-Flag aktualisieren,
nicht die Stufe hektisch nachziehen. Quellen-URLs:
- PB Langzeit: forschungsgruppe.de → Politbarometer → Langzeitentwicklung → Politik II (xlsx „Wichtige Probleme I/II")
- EB: europa.eu/eurobarometer (Standard-Eurobarometer, DE national)
- IP: ipsos.com/de-de/meinungsumfragen/sorgenbarometer
