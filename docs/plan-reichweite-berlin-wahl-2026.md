# Reichweiten-Pipeline — Berlin-Wahl 2026

**Stand:** 2026-06-03 · **Fixpunkt:** Wahl zum Abgeordnetenhaus **So, 20.09.2026** (~15 Wochen) · **Status:** Plan, vor Umsetzung

## Strategischer Kern (warum das überhaupt geht)

Neutralität deckelt Outrage-Viralität — aber baut einen **Vertrauens-Burggraben**: die eine Quelle, die *alle Lager* zitieren können. Ziel ist NICHT Dauer-Viralität, sondern **hoch-vertrauter Kern + Wahl-Spitze + Multiplikatoren**. Realistische Größenordnung: FragDenStaat/abgeordnetenwatch (engagierte Zehntausende, Massen-Spitzen um Wahlen) — genug für Legitimität, Spenden, echte Wirkung.

**Emotion ohne Haltung — vier Quellen (der Nutzer liefert die Emotion, wir die neutrale Linse):**
1. **Selbst-Relevanz** — „mein Abgeordneter / mein Gebiet" (PLZ-Feature = emotionale Eingangstür).
2. **Neugier/Überraschung** — wahre, überraschende Zahlen; Quiz-Mechanik.
3. **Rechenschaft als Transparenz** — Aussage vs. Abstimmung (nüchtern, **kein Gotcha** → [[feedback_no_gotcha_framing]]).
4. **Ermächtigung** — „endlich verstehe ich das" (Erklärseiten).

**Leitplanken (nicht verhandelbar):** Form klauen, nicht die Value Function ([[feedback_distribution_form_not_value_function]]); Gleichbehandlung aller Parteien; zeigen statt etikettieren; keine „umgesetzt"-Wertung bei Wahlprogrammen (nur deskriptive Zahl-Gegenüberstellung, [[project_next_level_research_2026-05-30]]).

## Die 3 Formate

| Format | Funnel-Rolle | Emotionsquelle | Datenbasis |
|---|---|---|---|
| **„Wer bin ich?"-Quiz** | Top — viral, spielerisch | Neugier/Spiel | DB-Felder ([[project_social_video_quiz_idea]]) |
| **„Mein Kandidat"** (PLZ→Direktkandidat:in AGH) | Mitte — persönlich, Conversion | Selbst-Relevanz | PLZ→Wahlkreis ([[project_plz_wahlkreis]]) + AGH-2026-Kandidaten |
| **„Was hat die Partei/der Abgeordnete wirklich gemacht?"** | Substanz — Bindung | Rechenschaft | Reden/Votes/Themenfelder ([[project_berlin_themenfelder]]) |

## Pipeline (rückwärts vom 20.09.)

- **Phase 0 — Launch-Reife (jetzt–Mitte Juni):** Ein-Satz-Positionierung festzurren ([[project_positioning_open]]); Public-Launch-Entscheidung (`noindex`/`robots: Disallow` raus, Datenschutzerklärung prüfen, [[project_demo_launch_hosting]]); „Unterstützen"-Link (Ko-fi/PayPal, einfache Variante, kein Verein) optional dran.
- **Phase 1 — Formate bauen (Mitte Juni–Mitte Juli):** Quiz-MVP; „Mein Kandidat" (PLZ→AGH-Direktkandidat:in); „was-gemacht"-Ansicht aus Themenfeldern/Votes. **Daten-Abhängigkeit:** AGH-2026-Kandidaten (Direkt je Wahlkreis + Listen) + ggf. Wahlprogramme müssen in die DB — Beschaffung früh klären.
- **Phase 2 — Vorglühen + Multiplikatoren (Mitte Juli–Ende Aug):** Quiz-Clips regelmäßig posten, *bevor* die Spitze kommt (Kanal warmlaufen). Parallel **Multiplikatoren-Outreach**: Redaktionen, Erklär-Creator, **Landeszentrale für politische Bildung Berlin**, Lehrkräfte — Embeds/Erwähnungen („powered by Politik-Radar") vorbereiten. ← wahrscheinlich höchster Hebel.
- **Phase 3 — Wahl-Push (1.–20. Sept):** getakteter Content, „gib deine PLZ ein", Kandidaten-/Themen-Vergleiche, Ramp bis Wahltag. Spitze am 20.09.
- **Phase 4 — Retention (nach der Wahl):** Spike-Publikum in Themenfeld-Follows + Spenden umwandeln; Anschluss-Story „was wird aus den Versprechen" (zahlt aufs Rechenschaft-Format ein).

## Erfolgsmaß (keine Vanity-Metriken)

Wiederkehrende Nutzer + Themenfeld-Follows + PLZ-Abfragen + Multiplikator-Einbettungen — **nicht** rohe Views. Spenden = Nebenprodukt + Legitimitäts-Signal, kein Ziel.
